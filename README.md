# Espousal — Myanmar site

Dubai property website for buyers from Myanmar, Burmese first with English.
Live at https://mm.espousalconstruction.com (GitHub Pages, custom domain in `CNAME`).

Pages are generated from one bilingual template: edit `_build.py`, then run `python3 _build.py`.
Forms send leads to the same Google Sheet and email as espousalsobha.com, tagged "Myanmar site".
